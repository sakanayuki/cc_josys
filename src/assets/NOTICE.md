# サードパーティ素材

## material-symbols-subset.woff2

Google の [Material Symbols](https://github.com/google/material-design-icons)
(Rounded / opsz 24, wght 400, FILL 0, GRAD 0)から、本アプリで使用する
27アイコンのみをサブセット化したフォントファイルです。

- ライセンス: Apache License 2.0
- 著作権: Copyright Google LLC

外部CDNを参照せず自前ホストしているため、オフラインや外部接続が制限された
環境でもアイコンが表示されます。差し替える場合は Google Fonts の
`css2?family=Material+Symbols+Rounded:...&icon_names=<使用アイコン名>` が返す
woff2 を同じ名前で置き換えてください(アイコンを追加したときも同様)。
